## Project Overview

An open-source Python package published on PyPI engineered to accelerate exploratory data analysis (EDA) by providing automated routines for dataset inspection, summary statistics, missing data analysis, and visual diagnostics.

## Key Features

- **Data Profiling & Inspection**: Automated identification of data types, cardinality, skewness, and outliers across structured datasets.
- **Missing Value Diagnostics**: Specialized routines to quantify, visualize, and summarize missing value mechanisms and patterns.
- **Descriptive Statistics**: One-line generation of univariate and bivariate distribution metrics.
- **Visualization Suite**: Clean visualization helpers for quick correlation analysis, distribution plotting, and data quality reports.
